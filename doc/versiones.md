##  Versión 2.0.0 (Actual)
**Estado:** `ESTABLE` | **Fecha:** Febrero 2026

En esta versión hemos dado el salto definitivo hacia la escalabilidad, transformando la estructura base en un sistema robusto y preparado para el entorno real.

###  Mejoras y Correcciones
* **[Arquitectura]**  Migración de monolito modular a **Microservicios**.
* **[Seguridad]**  Implementación de **Spring Security** con autenticación mediante **JWT**.
* **[Persistencia]**  Transición de base de datos local a **Base de Datos Externa** (MySQL/MariaDB).
* **[Interfaz]**  Rediseño total del frontend utilizando **Tailwind CSS** y fragmentos de **Thymeleaf**.
