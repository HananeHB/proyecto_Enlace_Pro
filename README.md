# Proyecto : EnlacePro
***Plataforma de adaptación lingüística para Aulas de Enlace (Secundaria).***

--- 
**Introducción**
Enlace Pro es una aplicación pensada para facilitar el trabajo de profesores y el aprendizaje de los alumnos en el Aula de Enlace de Secundaria. 
  
  Está desarrollada en **Spring Boot**, sigue el  **patrón hexagonal** y utiliza la técnica de **vertical slicing** para contruir cada funcionalidad de foma completa e independiente.
